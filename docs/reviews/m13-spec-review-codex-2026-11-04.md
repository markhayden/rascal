# m13-spec-review (Codex, 2026-11-04)

Read-only review; every finding was folded into SPEC.md draft 9 and PLAN.md M13.

1. **blocker — [SPEC.md:816](SPEC.md:816): The generic checker exchange is not specified.** Table-manners currently leaves verdicts in the tool-owned body and requirement schemas to each action. Squint’s `locations.found` also includes findings beyond removal failures. **Fix:** define a narrow, opt-in 0.5.0 capability with an exact request example, a typed verdict, and locations specifically identifying remaining target material. Specify null/error behavior and capability discovery; avoid a general action-schema translation layer.

2. **major — [SPEC.md:842](SPEC.md:842): Per-try spending conflicts with whole-call reservation.** Table-manners §4.5 reserves the call’s worst case before paid work; rascal currently prices one filler call. The draft defines neither reservation for the ladder nor enforcement of the checker’s declared price. **Fix:** choose the affordable maximum number of tries before execution, reserve that bound against both caps, and pass an explicit `max_spend_usd` to each checker call. Aggregate actual, estimated, unresolved, and cached spend across every try.

3. **major — [SPEC.md:836](SPEC.md:836): Location-guided segmentation has no defined input or frame conversion.** `segment` has no region input. Checker locations refer to the candidate’s file identity, while segmentation reads the baseline; masks may inhabit `cut:` or `crop:` frames. **Fix:** define an ROI input or an explicit crop-and-map procedure, validate the returned candidate reference, and record the geometry’s transfer to the baseline and mask frame. Recompute the filler window each try; retain completed candidates if expanded support exceeds `max_side`.

4. **major — [SPEC.md:843](SPEC.md:843): “Failed check” conflates verdict and operational failure.** Squint legitimately exits 1 for `fail` and 2 for `unsure`; treating checker commands like fillers would stop the ladder on both. Timeout, malformed output, cancellation, and refusal handling are unspecified. **Fix:** make the validated result status authoritative, explicitly accept completed verdicts despite those exits, and define process timeout, output bounds, cancellation, parent status, and spend treatment. Preserve completed images on operational failure.

5. **major — [SPEC.md:830](SPEC.md:830): The ladder assumes recipe structure that eligibility does not require.** Any recipe declaring `inputs.prompt` qualifies, but retries assume `segment`, `grow.px`, `close`, `plug`, `subtract`, and `feather`. “Planes join the mask” also leaves unclear whether new planes receive normal growth and shadow treatment or whether previously shaped pixels are shaped again. **Fix:** scope M13 to shipped `remove-prompt` and write its exact state transition, including cumulative planes, effective overrides, overlapping ROIs, instance limits, protect application, and stopping when the effective mask identity is unchanged.

6. **major — [SPEC.md:845](SPEC.md:845): The selection rule does not establish the owner’s “best try.”** The last failed try can have more spill and no better removal than the first; recency supplies no quality evidence. **Fix:** define “best” operationally, including the comparison and tie-break. If only verdict categories rank tries, say so explicitly. Record `selected_try`, place its result first, and ensure the primary Mask and preview belong to that same try.

7. **major — [SPEC.md:851](SPEC.md:851): Recording verdicts does not define reproducible replay.** Finder packs and fillers can also vary, contrary to “everything but the checker’s verdict is fixed.” No checker request identity or `heal --replay` behavior is specified. Journal notes disappear when repair rebuilds committed operations. **Fix:** persist a durable per-try record binding baseline, mask, candidate, checker invocation/effective configuration, response, transition, and spend. Replay must reuse recorded external outputs and refuse missing recordings without making calls.

8. **major — [SPEC.md:771](SPEC.md:771): The re-export needs an explicit ABI and parity gate; “best, as before” is inaccurate.** `export.py:89` requests single-mask mode and strips the mask axis; runtime accepts no points. `MODEL.md:43` documents an already-fixed box axis. Upstream supports combined boxes and points, but single-mask mode uses a separate token with optional stability fallback, rather than simply choosing the highest-IoU multimask. ([Pinned upstream implementation](https://github.com/huggingface/transformers/blob/v4.57.6/src/transformers/models/sam2/modeling_sam2.py)) **Fix:** specify tensor shapes, point labels/padding and bounds; require ONNX parity for all three masks and IoUs with box-only and multiple-point inputs. Describe `best` as new behavior.

9. **major — [SPEC.md:848](SPEC.md:848): Optional checker readiness conflicts with the current readiness rules.** Table-manners marks readiness `needs_setup` when a listed requirement is missing; rascal’s implementation follows that rule. Merely listing the missing checker key could make a host disable removal. **Fix:** define how optional check requirements are exposed separately from blocking removal requirements. Resolve effective checking before call readiness and estimation, and record the unchecked reason in the invocation/result.

10. **major — [SPEC.md:784](SPEC.md:784): “The blob around it” does not define `plug`’s denominator.** Connected components can merge after `close`, surround several holes, or contain islands. Counting newly filled pixels can make later holes qualify depending on traversal order. **Fix:** define foreground connectivity, surrounding-component assignment, and whether area includes holes or islands. Freeze labels and denominators before filling, and explicitly reuse refinement postconditions that clear core under protect. Test merged instances, multiple holes, diagonal escapes, border openings, and protected holes.

11. **major — [SPEC.md:780](SPEC.md:780): A component centroid is not necessarily a positive point.** A U-shaped component or ring can have its centroid in background, directing the retry toward pixels outside the object. Fragmentation also permits an unbounded number of points. **Fix:** select an actual component pixel nearest the centroid with a fixed tie-break, define component connectivity, and cap points using a deterministic component ordering shared with the exported graph.

12. **major — [SPEC.md:760](SPEC.md:760): M13 has no explicit acceptance section.** The existing testing strategy does not cover the ladder, optional checker, new geometry rules, or multimask export. **Fix:** add offline acceptance commands using scripted checkers for pass, fail/unsure retries, exhaustion, refusal, missing key, cap exhaustion, cancellation, replay, overlapping locations, and protect preservation. Add synthetic shaping fixtures and a private owner-reviewed reproduction of the motivating collar failure.

13. **major — [SPEC.md:810](SPEC.md:810): Lab selection is not connected to production export feasibility.** Candidates run “as published,” but ADR 0018 requires an ONNX-only bundle. A winning PyTorch candidate may not survive export or match its lab masks. **Fix:** make adoption conditional on exporting the selected winner, parity-checking it on the corpus, and passing offline pack acceptance. This requires exporting only the winner, as decided.

14. **minor — [SPEC.md:774](SPEC.md:774): Several deterministic choices remain undefined.** Equal areas/IoUs, empty candidates, component ordering, double-padding relative to the original versus padded box, and whether `outline="best"` changes retry selection all need decisions. Per-instance measurements also exceed today’s `MAX_INSTANCES + 2` envelope bound. **Fix:** specify these cases, parameter bounds, numeric measurement names/meanings, and updated manifest limits.

15. **minor — [SPEC.md:800](SPEC.md:800): The lab’s common comparison and scores are underspecified.** Not every candidate exposes three masks, comparable predicted IoUs, or the same retry interface. “Final mask” could mean core or feather support, and spill has no denominator. **Fix:** document small per-candidate adapters and inapplicable stages; freeze prompts and shaping settings; define the scored binary plane, spill formula, empty-mask handling, and warm/cold timing. Keep the script lab-only.

16. **minor — [SPEC.md:24](SPEC.md:24): Draft 9 leaves contradictory governing text.** Assumption 4 excludes controllers and checker models; decision 7 still prohibits the loop; the `heal` graph remains single-pass; the external-interface section pins only 0.4.0. **Fix:** amend those passages alongside ADR 0023, explicitly naming the bounded removal exception and the 0.5.0 capability dependency.

Overall verdict: **Not ready to build without specification decisions.** Resolve the checker exchange, spend reservation, retry transition/frame rules, and replay record first.
