1. **Blocker — The conversion parity check cannot be implemented as written.** [SPEC.md:1153](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1153)  
   The catalogue supplies expected **mask digests**, but acceptance requires IoU ≥ 0.999. A digest supports exact equality; it cannot yield intersection or union pixels. Instance matching and empty-mask behavior are also unspecified.  
   **Fix:** Ship reference binary masks, authenticated by digests, plus the exact preprocessing, prompt, threshold and matching rule. Define unmatched instances, empty masks and score tolerances. Require a nonempty positive case so an always-empty implementation cannot pass.

2. **Blocker — SAM 3’s external weights fall outside the specified integrity check.** [SPEC.md:1148](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1148)  
   Provenance records “each graph’s SHA-256,” but the lab established that the vision graph requires external data. Hashing its `.onnx` file does not authenticate those weights. The existing exporter explicitly saves without external data (`tools/python/export/export.py:104`), so its single-file assumptions cannot carry over. Installation, cancellation and removal also lack a definition of the complete file set.  
   **Fix:** Define one model manifest covering all three graphs, external-data files, tokenizer/configuration assets and notices, with sizes and digests. Reject external references escaping the installation directory, including symlink escapes, and verify the complete set before loading.

3. **Major — The credential route conflicts with the existing process boundary and session contract.** [SPEC.md:1141](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1141)  
   Get needs `HF_TOKEN`, but `SPEC.md:1391` strips every `_TOKEN` variable from pack processes even when explicitly allowlisted. Furthermore, entering a credential in Wafflery cannot change an already-running server’s environment: `../table-manners/CONTRACT.md:623` requires a deliberate restart and new session.  
   **Fix:** Specify a separate installer subprocess and narrowly scoped credential allowance; keep inference packs credential-free. Define how Wafflery discovers installable credentials and deliberately refreshes the session after credential entry. Pass the token only to the authenticated downloader, not dependency installation or conversion.

4. **Major — Parity is being used as a trust decision it cannot establish.** [SPEC.md:1151](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1151)  
   Matching one fixture establishes limited behavioral agreement, not trusted origin or safe execution. The graphs have already executed when parity passes. Recording checkpoint digests after downloading and trusting a neighboring provenance file does not establish that either came from the approved conversion. A dependency lock also does not identify the converter’s own code.  
   **Fix:** Pin and verify the complete upstream snapshot and converter source before execution; record converter-code and lock digests. Specify safe checkpoint loading, no unreviewed remote code/custom operators, and the ownership boundary for locally generated provenance. Require HTTPS with defined redirect/authentication handling, bounded downloads and sanitized errors. Describe parity as a correctness gate, separate from provenance and integrity.

5. **Major — Get depends on converter material that an installed user does not receive.** [SPEC.md:1145](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1145)  
   `tools/python/convert/` is a repository path, explicitly excluded from the bundle. The current wheel packages only `src/rascal_tools` (`tools/python/pyproject.toml:28`); the referenced fixture also lives outside it. Nothing specifies how a release installation obtains the converter code, lock and fixtures.  
   **Fix:** Distribute these small resources in the package, or fetch a versioned, digest-pinned converter archive. Keep its heavyweight environment separate. Specify interpreter/uv discovery, supported platforms and installation location. Acceptance must start with a released installation, no source checkout and empty caches.

6. **Major — Per-choice readiness is internally contradictory and lacks a wire format.** [SPEC.md:1174](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1174)  
   A `for_choice` requirement “never” causes `needs_setup`, yet the missing default must do exactly that. The public contract uses JSON Schema `params_schema`, not the pack’s `type: choice` representation (`../table-manners/CONTRACT.md:256`). The draft never defines where choice requirements live or how a choice links to its installable.  
   **Fix:** Specify the actual JSON shape and a readiness truth table: description evaluates the resolved default; calls and estimates evaluate their selected choice. A missing default must not prevent explicitly selecting another installed model. Keep installation credentials separate from inference requirements, and define unavailable/unconfirmed choices.

7. **Major — Install controls lack the lifecycle needed by their promised UI.** [SPEC.md:1186](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1186)  
   Referring to contract §§4.1–4.2 is insufficient: those sections describe run-associated progress and cancellation, while installation explicitly creates no run. Result/error schemas, duplicate requests, disconnect reconciliation, concurrency, and cancellation near completion are undefined. Wafflery expects work to survive tab closure (`../wafflery/SPEC.md:54`).  
   **Fix:** Define control request/result/refusal schemas, progress without a run reference, cancellation behavior, operation ownership and how a reconnect discovers an ongoing or completed installation. Explicitly update reserved controls and version adoption in table-manners, rascal and Wafflery; the latter currently pins exactly 0.5.0.

8. **Major — Installation/removal is not atomic across files or coordinated with loaded models.** [SPEC.md:1162](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1162)  
   Shared-file retention alone does not handle concurrent Get/Remove, crashes, failed reinstalls or inference during removal. Existing `cache.py:32` caches verification by filename, and `segment.py:128` retains sessions. Replacing a file can therefore leave stale verification or a previously loaded model behind the newly reported state.  
   **Fix:** Stage and verify a complete installation, then publish it atomically under a cross-process lock. Preserve the old installation on failure. Define active-use protection, shared-file ownership, cache invalidation and removal of loaded models. Cancellation must remove only files owned by that installation attempt.

9. **Major — Model selection is not fully connected to recipes, retries or the public operation surface.** [SPEC.md:1202](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1202)  
   The shipped recipe has no model binding (`crates/rascal-mask/recipes/remove-prompt.toml:14`). Precedence among a call argument, step override, recipe parameter and configuration is undefined. M13 crop retries specify only the prompt and halved threshold, leaving propagation of the selected model unresolved. Also, the existing external interface expressly excludes pack `segment` from public operations (`SPEC.md:426`, `1602`), whereas M14 promises its description and MCP selection.  
   **Fix:** Define one resolution rule and propagate the resolved selection through initial segmentation and every retry. Specify the public `segment` action’s ports/results and the mapping from `remove_prompt` to `remove-prompt`. Define behavior for configured third-party packs that do not support this catalogue.

10. **Major — The pipeline interface leaves materially different inference behavior unspecified.** [SPEC.md:1108](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1108)  
    “Returns instances” leaves implementers to choose SAM 3 query splitting, score meaning, filtering, cross-query duplicates, ordering, mask thresholding and region geometry. BiRefNet’s box/crop conditioning and mapping back to the image are likewise unspecified. Existing behavior is much more precise in `MODEL.md:63`. Accepted `pad`, `outline` and `min_cover` arguments also need defined treatment when unsupported.  
    **Fix:** Specify each adapter’s preprocessing/postprocessing and the common instance record, including deterministic ordering and region–plane correspondence. Declare applicable settings per model; reject unsupported explicit overrides or report them clearly as inapplicable. Preserve M13’s established rules for Tiny.

11. **Major — A string model ID cannot be a measurement under the current envelope.** [SPEC.md:1209](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1209)  
    Measurements are numeric: `schemas/copied/envelope-v1.json:201` requires a number, and `Answer.measure` converts values to `float`. Adding `"sam3"` would fail construction or boundary validation. The measurement-count bound is unchanged too.  
    **Fix:** Record model identity in resolved parameters, provenance and the contract invocation. Keep measurements numeric. There is no need to change the copied schema for this purpose.

12. **Major — Recording only the catalogue ID loses installation identity and can break replay expectations.** [SPEC.md:1203](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1203)  
    Two locally converted installations can have different bytes under the same `sam3` ID. Provenance remains beside the model, so removal can erase the evidence behind a saved run. Existing lab keys include bundle/configuration revision but not dynamically installed model content (`SPEC.md:1476`). Meanwhile, unconditional missing-model refusal conflicts with recorded replay, which must not start the pack (`SPEC.md:1419`).  
    **Fix:** Record a model-installation identity covering all artifacts, converter and adapter versions in run evidence and relevant cache/estimate identities. Preserve that metadata with the run. Specify that recorded-output replay works without installed models, while fresh execution validates its selected installation.

13. **Major — The new catalogue does not redefine existing fetch and bundle membership.** [SPEC.md:1088](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1088)  
    `fetch.py:88` downloads every artifact, and `scripts/build-bundle.sh:82` requires and copies every manifest entry. Adding BiRefNet to the existing manifest would consequently make it part of the bundle—or prevent a Tiny-only bundle from satisfying the build’s model check. This contradicts M14’s default-only bundle promise.  
    **Fix:** Separate artifact inventory from installation selection. Define the bundled default’s dependency closure and the behavior of legacy `fetch`. Build releases from an explicit permissive allowlist, never from whatever models happen to be installed. Test that a cache containing SAM 3 cannot cause its files to enter a release.

14. **Major — The licence conclusion overstates what direct downloading achieves.** [SPEC.md:1226](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1226)  
    “The maker’s terms never pass through rascal” is too broad. The SAM License covers use and modification as well as redistribution, includes code within SAM Materials, requires terms to accompany redistributed derivatives, and includes indemnity for use or distribution. Avoiding redistribution is a defensible owner policy, but does not eliminate obligations for users or rascal’s own lab use. [Meta’s SAM License](https://huggingface.co/facebook/sam3/blob/main/LICENSE)  
    **Fix:** State the narrow policy: rascal does not distribute SAM Materials or converted weights. Record the licence version/text digest and source; audit converter code and bundled resources separately from weights. Explain that local conversion retains applicable terms and document production transfer obligations. Keep Decision 15 and the ADR amendment explicit approval dependencies.

15. **Major — Acceptance can pass without proving the shipped adapters or offline runtime work.** [SPEC.md:1235](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1235)  
    Fake converters and tiny graphs cannot establish actual SAM 3/BiRefNet preprocessing, external-data loading or supported-platform behavior. A manual side-by-side run does not replace M13’s corpus parity and offline adoption gate (`SPEC.md:882`). The supplied ≥0.9997 lab result is useful evidence, but does not prove the packaged runtime path.  
    **Fix:** Retain gated real-model acceptance using already-provisioned artifacts, with network disabled, including non-square images, multiple queries, empty results and M13 retries. Add corruption, interrupted installation and concurrent lifecycle tests. Explicitly allow loopback fixture servers in the testing policy, or use an injected transport to preserve its literal “no network” rule.

16. **Minor — Several promised catalogue displays have no defined data or semantics.** [SPEC.md:1062](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1062)  
    The UI promises CPU time, machine availability and a removal score, but the example/schema lacks timing hardware, compatibility criteria and a definition of `remove`. The referenced `docs/results/segment-01.md` is absent. A single size field also cannot distinguish download size, installed size and peak conversion disk use; 3.4 GB of graph files is not a demonstrated peak-memory requirement.  
    **Fix:** Define these fields and their measurement context, or omit unavailable values. Publish a non-private results summary with metric definitions and clearly label measured versus estimated resource requirements.

17. **Minor — The generic installer and component catalogue enlarge the first implementation unnecessarily.** [SPEC.md:1122](/Users/markhayden/go/src/github.com/markhayden/rascal/SPEC.md:1122)  
    Separate detector/outliner catalogues and a generic installer anticipating fillers add interfaces beyond selecting three supported segmenters. Shared artifact references already provide file deduplication.  
    **Fix:** Start with a flat segmenter catalogue referencing shared artifacts and explicit adapter IDs, one model argument, and narrowly specified model installation controls. Generalize component composition and other installable kinds when a concrete second consumer requires them.

**Verdict: not ready to plan.**
