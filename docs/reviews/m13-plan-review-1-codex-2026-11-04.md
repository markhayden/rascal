# m13-plan-review-1 (Codex, 2026-11-04)

Read-only review; every finding was folded into SPEC.md draft 9 and PLAN.md M13.

1. **Major — [PLAN.md:3609](PLAN.md:3609), 13.12 step 1:** Budget-dependent `N` has no concrete integration task. `estimate::price()` cannot see session holdings; `actions.rs:468` prices before locking the ledger, then refuses an unaffordable reservation. Merely pricing three tries would reject calls that could afford one. **Fix:** choose and reserve `N` atomically under the ledger lock, pass it into heal, and test depleted budgets and concurrent calls alongside per-call caps.

2. **Major — [PLAN.md:3675](PLAN.md:3675):** Adding `checker call:` notes does not account for checker spend. `run_json.rs:326` calls `filler::spent()`, which recognizes only filler records. No task explicitly updates aggregation or session settlement. **Fix:** implement combined per-try/run/session accounting, including measured checker spend, unresolved calls, cache hits and unused reservations; assert totals after early pass, failure and cancellation.

3. **Major — [PLAN.md:3598](PLAN.md:3598), 13.15:** The prescribed checker setup inherits an invalid spec example. Squint’s `Obligation` requires `id` and `kind`, accepts `text`, and rejects unknown fields; `{must_not = "…"}` will fail before checking anything. **Fix:** reconcile the example with squint’s native `{id = "RQ1", kind = "must_not", text = "…"}` shape, without a shim. Add an early offline integration test through the actual `squint call` CLI, including image arguments and allowed directories.

4. **Major — [PLAN.md:3556](PLAN.md:3556):** The fixture dependency order cannot satisfy the stated gates. Task 13.8 bumps the contract and requires `cargo test` before its producers adopt it. Table-manners’ `tests/fixtures.rs:98` requires every fixture’s version to equal the crate’s version. Later tasks also lack an explicit final copy of loop fixtures into table-manners. **Fix:** separate draft schema work from a coordinated fixture checkpoint: producers regenerate their own complete sets, copy them into the contract repo, then run full conformance before publication.

5. **Major — [PLAN.md:3719](PLAN.md:3719):** Wafflery’s adoption is much larger than changing its pin and rendering new fields. `src/tools/mod.rs:82`, bundle/handoff code, `ui/src/api/tool-session.ts`, and `encodeBindings()` explicitly require `0.4.0`. They will reject 0.5 documents. **Fix:** add a complete 0.5 adoption slice covering validators, sessions, submissions, bundles, handoffs, sample peer and fixtures; replace the old version directly and update its docs.

6. **Major — [PLAN.md:3672](PLAN.md:3672), 13.14:** The transport between try records and Wafflery is unspecified. The contract has no generic `tries` field, while Wafflery selects outputs by `role` (`SavedComparison.tsx:94`); repeated `result` roles cannot distinguish tries. Existing heal/render code also writes fixed filenames. **Fix:** define persistent per-try files and distinct output roles, keep selected outputs first, and specify how generic labels and check summaries reach Wafflery. Test selecting an earlier try after all later files exist, including its mask artifact and preview.

7. **Major — [PLAN.md:3281](PLAN.md:3281), 13.6/13.15:** The lab dependencies do not deliver the required comparison. Task 13.1 removes the baseline decoder before 13.6 runs; 13.6 does not depend on 13.3’s shipped shaping. Track C can also release before the lab/pick despite the spec’s explicit build order. **Fix:** preserve a separate pinned pre-M13 baseline environment and model cache before replacement; require completed shaping for the round, and gate the loop’s delivery on the lab and adoption.

8. **Major — [PLAN.md:3313](PLAN.md:3313):** `m13.1` is not guaranteed to contain track A alone: contract/config work may already have landed on the shared milestone branch. “Cherry-picked … from `m13.1`” also does not identify the complete commit set. **Fix:** keep track A isolated from the recorded base, list its commits explicitly, and verify the fallback on `=0.4.0` with no path dependency before declaring the checkpoint usable.

9. **Major — [PLAN.md:3315](PLAN.md:3315):** Git reversal does not restore the working installation. Task 13.15 adds `[checker]` to external config; the old `Config` uses `deny_unknown_fields` and will reject it. Pack installs and model caches also need restoration. Additionally, “Track B … never code” contradicts 13.7’s runtime/export changes. **Fix:** record matching binary, pack, model and config checkpoints, document installation/restoration steps, and include winner adoption in code rollback.

10. **Major — [PLAN.md:3476](PLAN.md:3476):** `generate.py` is a panorama generator, not a neutral object-scene generator. It prepends spherical instructions, requests 21:9, and resizes output to 2:1. Supplying `objects.json` retains those transformations. **Fix:** add an explicit flat-image generation path before approving spend, preserve native geometry, and identify exactly which image bytes the owner masks and the harness scores.

11. **Minor — [PLAN.md:3623](PLAN.md:3623), 13.1/13.5/13.14:** Several verification instructions fail or can pass without verifying the requirement. `check-contract.sh` rejects path pins; Wafflery has neither `just check` nor `scripts/check-ui.sh`; `rascal lab corpus verify` does not exist. Bundle acceptance can skip segment entirely. **Fix:** use the repos’ actual commands, explicitly handle draft-pin checking, provide the corpus verifier, and require `BUNDLE_MODELS=required` for model acceptance.

12. **Minor — [PLAN.md:3641](PLAN.md:3641):** A byte-identical journal golden is nondeterministic. Workspace journal records include measured durations, as do filler calls. **Fix:** define normalization for observational timing and machine-dependent paths, compare semantic records and identities, and compare produced image bytes separately.

13. **Minor — [PLAN.md:3695](PLAN.md:3695):** Task 13.12 combines process execution, geometry, retries, accounting, selection, journaling and reporting into one commit; splitting only after it exceeds undefined “review size” is not an executable boundary. **Fix:** pre-split into one checked try, one located retry, and bounded multi-try selection/output preservation, each with explicit acceptance. Reflect those slices in `tasks/todo.md`.
