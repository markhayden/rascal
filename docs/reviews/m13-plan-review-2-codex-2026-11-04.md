# m13-plan-review-2 (Codex, 2026-11-04)

Read-only review; every finding was folded into SPEC.md draft 9 and PLAN.md M13.

Round-one findings 1, 2, 4, 5, 7, 8, 10, 12 and 13 are addressed. Findings 3, 6, 9 and 11 remain partially unresolved below.

1. **Major — PLAN.md:3659, 13.9: the checker example still lacks valid image arguments.** `SPEC.md:908` supplies strings for `source` and `candidate`; squint’s `contract.rs:880` requires native image objects such as `{"path": "/abs/image.png"}`. The corrected requirements shape does not resolve this. **Fix:** use nested `{ path = "{source}" }` / `{ path = "{candidate}" }` templates, reconcile the spec example, and test that exact configuration without a shim.

2. **Major — PLAN.md:3742, 13.12a: the allowed directory excludes the source under `serve`.** `heal.rs:464` obtains the source from the workspace, which can be outside the run directory. Squint canonicalizes paths and rejects images outside `--allow-dir`. **Fix:** stage both checker input files inside the allowed run directory and test with the shared workspace elsewhere. Document an absolute squint executable path too: Wafflery supplies a system-only `PATH` (`src/tools/environment.rs`), excluding typical Cargo installations.

3. **Major — PLAN.md:3769, 13.12b: existing crop operations cannot implement the retry literally.** `window` constructs a square support crop with additional context; it does not crop directly to a padded bbox. `unwindow` always emits `Role::Composite` (`unwindow.rs:108`), which `select` rejects (`select.rs:111`). **Fix:** specify exact bbox cropping and a mapping helper that commits the expanded image as `Role::Plane`, preserving existing op semantics. Add a non-square, offset crop test asserting exact raw-frame pixels.

4. **Major — PLAN.md:3381, 13.1: release bundles will fetch the wrong decoder.** `.github/workflows/bundles.yml:47` still downloads only `models-2026-10`. Updating `artifacts.toml` to require `decoder3.onnx` makes clean release builds fail with models required. No task updates this workflow. **Fix:** add workflow adoption to 13.1, preferably fetching the manifest’s artifacts, and verify both platform bundles from empty model caches.

5. **Major — PLAN.md:3797 and 3842, 13.12c/13.14: the host transport remains incomplete.** The plan records checker verdicts inside tries, but specifies no generic mapping to the outer rascal result that Wafflery renders. Simply forwarding a header verdict also conflicts with the undeclared `answers` on `remove_prompt` and its unchecked completed runs. Separately, Wafflery’s `evidence.rs:235` discards output labels, and `SavedImage` has no label field. **Fix:** define the selected-check transport and unchecked/failure semantics explicitly; preserve labels through capture, storage and UI types. Test reopening a saved run.

6. **Major — PLAN.md:3346: draft checkpoints still cannot restore a working installation.** A rascal tag does not restore its sibling table-manners checkout. After 13.15, a checkpoint’s `=0.4.0` path dependency encounters the sibling’s `0.5.0`. Also, syncing `tools/python` does not replace the installed pack named by the owner’s configuration. **Fix:** record matching repository SHAs at each checkpoint, restore them in isolated sibling checkouts, and provide pack installation/configuration commands. Verify restoration after the final installation.

7. **Major — PLAN.md:3468, 13.3: the diagonal-hole acceptance contradicts the algorithm.** Four-connected background components treat an interior pocket connected to the exterior only diagonally as a hole. “A diagonal escape counts as no hole” requires different connectivity. This contradiction also exists between SPEC.md’s algorithm and acceptance. **Fix:** reconcile the spec before building; if four-connectivity stands, assert that a diagonal-only escape remains enclosed, while an orthogonal escape does not.

8. **Major — PLAN.md:3572, 13.6: adapter planes have no specified route into shipped shaping.** `rascal call` cannot run an arbitrary recipe suffix; importing adapter PNGs produces canonical images, while `select` requires plane-role images. The baseline’s pack-only `segment` is also not a `rascal call` action. **Fix:** establish a lab-only adapter pack, or another concrete supported bridge, before implementing every candidate. Require one offline adapter→`rascal call`→final-core smoke test and specify the baseline route.

9. **Minor — PLAN.md:3323 and 3406: verification instructions remain incorrect.** Wafflery has no root `package.json`; its typecheck/unit commands need `--cwd ui`, and its prebuilt UI must be regenerated before `check-ui.ts`. `build-bundle.sh` requires platform and output arguments; `acceptance.sh` rebuilds its own bundle rather than consuming the earlier one. **Fix:** use the documented Wafflery commands and `BUNDLE_MODELS=required scripts/bundle-acceptance.sh <binary> <scratch>` for model acceptance.

10. **Minor — PLAN.md:3631, 13.8: schemas cannot verify an action’s declaration across documents.** A result schema cannot determine whether its action declared `answers` in a separate description. Table-manners already handles comparable rules in semantic conformance tests. “A `where` on a pass” also needs clarification: the specified verdict includes an empty `where` array. **Fix:** put declaration matching in semantic tests; reject non-empty pass locations, not the empty array.

11. **Minor — PLAN.md:3274 versus 3884: publication order contradicts itself.** The repository table says table-manners merges at 13.16, **then** publishes; 13.15 publishes and switches consumers to crates.io before that merge. **Fix:** choose one sequence and identify the exact tested commit being tagged. Also make draft verification explicitly local-only or update CI: current workflows still invoke the supposedly skipped contract check and do not check out sibling path dependencies.

**Verdict: not ready to build.**
